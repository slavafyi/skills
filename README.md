# Agent Skills

This repository can host multiple portable agent skill plugins.

Plugin-specific documentation lives under `plugins/<plugin>/README.md`.

## Plugins

- [forge](./plugins/forge/) — workflow and project-memory skills for development agents.
- [shopify](./plugins/shopify/) — Shopify development workflow skills.
- [common](./plugins/common/) — common utility skills for coding agents.
